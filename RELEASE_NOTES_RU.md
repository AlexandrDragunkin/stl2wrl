# Release Notes - stl2wrl v1.1.0

## Новое в этой версии

### Основные улучшения
- Обновлены даты в комментариях до 2026 года
- Все зависимости и требования остались без изменений

### Совместимость и зависимости
- Поддержка Python версий 3.7-3.12
- Для работы с бинарными STL файлами требуется установка:
  - numpy (версия 1.19.0 или выше)
  - numpy-stl (версия 3.1.2)
- Для среды K3 (Python 3.7 32-bit Windows only):
  ```
  pip install numpy-stl==3.1.2 -U --target <UserProto>/site-packages
  ```

### Производительность
Тестирование производилось на системе Windows 11 с процессором AMD Ryzen 7 5800H:

#### Маленькая модель (zynq_chip.stl - масштаб 0.01):
- Время обработки: 1.38 секунды
- Команда: `python stl2wrl.py demo\zynq_chip.stl 0.01`

#### Большая модель (440.stl - масштаб 1.0):
- Размер файла: более 150 МБ
- Время обработки: 18.17 секунды
- Команда: `python stl2wrl.py demo/440.stl 1`

### Использование
Преобразование STL файла в WRL формат:
```
# Коэффициент масштабирования 2.54 для конвертации мм/дюймы
# Результат сохраняется в demos/zynq_chip.wrl, готов для импорта в KiCAD
./stl2wrl.py demos/zynq_chip.stl 2.54
```

### Интеграция с KiCAD
- Поддержка импорта в KiCAD
- Совместимость с отпечатками компонентов (footprints)
- Поддержка крупных 3D моделей
